🌉 Jembatan Lengkung

Lengkungan jembatan gantung berbentuk parabola — dirancang dengan fungsi kuadrat agar kuat!

❓ PERTANYAAN PEMANTIK (klik untuk arah diskusi)

1. Grafik y = x² dan y = −x² — apa bedanya? 👆 klik

💬 Arah diskusi: y = x² membuka ke atas ⛰️ (punya titik terendah), y = −x² membuka ke bawah 🌋 (punya titik tertinggi). Penentunya: tanda a!

2. Parabola y = x² − 4 memotong sumbu-x di mana? 👆 klik

💬 Arah diskusi: y = 0 → x² = 4 → x = 2 atau x = −2. Titik potong sumbu-x = akar-akar persamaan kuadratnya — materi Bab 2 kepakai lagi! 🔗

3. Mengapa pedagang ingin tahu "keuntungan maksimum"? 👆 klik

💬 Arah diskusi: Karena keuntungan sering berbentuk parabola yang membuka ke bawah — puncaknya = untung terbesar! Di misi ini kamu hitung puncaknya. 💰

Tahap 6 • Materi 2

📗 MENUJU PUNCAK ⭐

Satu ide: sumbu simetri x = −b/2a — cerminkan parabola, lalu hitung nilai optimumnya!

xp = −b / 2a  →  yp = f(xp)

a > 0 → yp = nilai minimum  •  a < 0 → yp = nilai maksimum

Tahap 7 • Materi 3

📙 AKSI NYATA 🌍

Satu ide: "maksimum/minimum" di soal cerita = nilai optimum di titik puncak!

📌 Jurus: tulis model fungsinya → hitung xp = −b/2a → hitung yp = f(xp) → jawab sesuai pertanyaan!
  1. 1️⃣ Bola: h = −5t² + 20t. Tinggi maksimum?
    tp = −20/(2·−5) = 2 → h(2) = −20 + 40 = 20 m ⚽
  2. 2️⃣ Untung: P = −2x² + 40x − 100 (ribu rupiah). Untung maksimum?
    xp = −40/(2·−2) = 10 → P(10) = −200 + 400 − 100 = 100 ribu 💰
