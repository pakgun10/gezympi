Tahap 3 • Apersepsi

💡 SEIMBANG & TAK SEIMBANG

Hidup penuh persamaan (=) dan ketidaksamaan (<, >, ≤, ≥). Kenali bedanya!

⚖️ Timbangan Seimbang

Kiri: 2 kotak + 3 kg. Kanan: 11 kg. Seimbang! → 2x + 3 = 11. Inilah persamaan.

🎟️ Tiket Wahana

"Minimal 12 tahun" → umurmu ≥ 12. Bukan persamaan — ini pertidaksamaan!

❓ PERTANYAAN PEMANTIK (klik untuk arah diskusi)

1. Timbangan: 2 kotak + 3 kg seimbang dengan 11 kg. Berat 1 kotak? 👆 klik

💬 Arah diskusi: 2x + 3 = 11 → 2x = 8 → x = 4 kg. Rahasianya: apa yang dilakukan di kiri, lakukan juga di kanan — timbangan tetap seimbang! ⚖️

2. "Uang sakumu minimal Rp10.000." Tuliskan kalimat matematikanya! 👆 klik

💬 Arah diskusi: x ≥ 10.000 — "minimal" = lebih dari atau sama dengan. Kata kuncinya: minimal (≥), maksimal (≤), lebih dari (>), kurang dari (<).

3. Apa beda x + 5 = 12 dengan x + 5 > 12? 👆 klik

💬 Arah diskusi: Yang pertama punya satu jawaban (x = 7). Yang kedua punya banyak jawaban (x > 7: 8, 9, 10, …)! Itulah beda = dan >.

Tahap 5 • Materi 1

📘 TIMBANGAN PERSAMAAN

Satu ide: SPLSV bentuknya ax + b = c. Jurusnya: operasikan kedua ruas dengan bilangan yang sama — timbangan tetap seimbang!

📌 Jurus: ax + b = c → x = (c − b) / a. Contoh: 2x + 3 = 11 → 2x = 8 → x = 4.
  1. 1️⃣ 3x − 5 = 10 → tambah 5 kedua ruas: 3x = 15 → bagi 3: x = 5
  2. 2️⃣ 7 − 2x = 1 → kurang 7: −2x = −6 → bagi −2: x = 3

⚖️ PEMECAH SPLSV — coba sendiri!

Isi a, b, c dari ax + b = c — lihat langkah penyelesaiannya!

Tahap 6 • Materi 2

📗 DUNIA KETIDAKSAMAAN

Satu ide: PtLSV pakai tanda < > ≤ ≥. Awas jebakan: dikali/dibagi bilangan negatif → tandanya DIBALIK! 🔄

< >

kurang dari / lebih dari.
Lingkaran kosong ○ di garis bilangan.

≤ ≥

maksimal / minimal.
Lingkaran penuh ● di garis bilangan.

🔄 Aturan Balik

×/÷ negatif → tanda dibalik!
cth: −2x > 8 → x < −4

📙 AKSI NYATA 🌍

Satu ide: soal cerita → ubah jadi model matematika → pecahkan!

📌 Jurus: misalkan yang ditanya = x → tulis persamaannya → selesaikan → cek kembali ke cerita!
  1. 1️⃣ 2 buku + Rp5.000 = Rp25.000. Harga 1 buku?
    2x + 5000 = 25000 → 2x = 20000 → x = Rp10.000 ✅
  2. 2️⃣ Uang Budi ≤ Rp50.000 untuk 3 mainan @Rp x.
    3x ≤ 50000 → x ≤ Rp16.666… (maksimal segitu!)
